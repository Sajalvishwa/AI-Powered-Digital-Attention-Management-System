# database.md — PostgreSQL Design

DB: PostgreSQL 16 · ORM: SQLAlchemy 2.x · Migrations: Alembic
Conventions: `snake_case`, plural table names, UUID primary keys, all timestamps `TIMESTAMPTZ` in UTC.

## 1. ER Overview
```
users 1───1 user_settings
users 1───* activity_sessions
users 1───* focus_sessions
users 1───* goals
users 1───* notification_events
users 1───* devices
devices 1───* activity_sessions
users 1───* refresh_tokens
```

## 2. Setup
```sql
CREATE EXTENSION IF NOT EXISTS "pgcrypto";   -- gen_random_uuid()
CREATE EXTENSION IF NOT EXISTS "citext";     -- case-insensitive email
```

## 3. Tables

### users
```sql
CREATE TABLE users (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name          VARCHAR(100) NOT NULL,
  email         CITEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  is_active     BOOLEAN NOT NULL DEFAULT TRUE,
  role          VARCHAR(20) NOT NULL DEFAULT 'user' CHECK (role IN ('user','admin')),
  created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### user_settings
```sql
CREATE TABLE user_settings (
  user_id              UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  daily_focus_goal_min INT NOT NULL DEFAULT 180 CHECK (daily_focus_goal_min BETWEEN 15 AND 720),
  idle_threshold_sec   INT NOT NULL DEFAULT 120 CHECK (idle_threshold_sec BETWEEN 30 AND 900),
  store_window_titles  BOOLEAN NOT NULL DEFAULT FALSE,
  ignored_apps         TEXT[] NOT NULL DEFAULT '{}',
  timezone             VARCHAR(64) NOT NULL DEFAULT 'Asia/Kolkata',
  theme                VARCHAR(10) NOT NULL DEFAULT 'dark',
  updated_at           TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

### devices
```sql
CREATE TABLE devices (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name        VARCHAR(100) NOT NULL,
  os          VARCHAR(30) NOT NULL,
  app_version VARCHAR(20),
  last_seen   TIMESTAMPTZ,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_devices_user ON devices(user_id);
```

### activity_sessions (core table)
```sql
CREATE TABLE activity_sessions (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  client_id    UUID NOT NULL,                       -- generated by desktop, idempotency
  user_id      UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  device_id    UUID REFERENCES devices(id) ON DELETE SET NULL,
  app_name     VARCHAR(255) NOT NULL,
  window_title TEXT,                                -- NULL unless user opted in
  is_idle      BOOLEAN NOT NULL DEFAULT FALSE,
  started_at   TIMESTAMPTZ NOT NULL,
  ended_at     TIMESTAMPTZ NOT NULL,
  duration_sec INT GENERATED ALWAYS AS (EXTRACT(EPOCH FROM (ended_at - started_at))::INT) STORED,
  focus_session_id UUID,                            -- FK added after focus_sessions
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  CONSTRAINT chk_time_order CHECK (ended_at >= started_at),
  CONSTRAINT uq_user_client UNIQUE (user_id, client_id)
);
CREATE INDEX idx_act_user_started ON activity_sessions(user_id, started_at DESC);
CREATE INDEX idx_act_user_app     ON activity_sessions(user_id, app_name);
```
> Scale note: if rows grow large, partition by month on `started_at` (later).

### focus_sessions
```sql
CREATE TABLE focus_sessions (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  label       VARCHAR(120),
  planned_min INT NOT NULL CHECK (planned_min > 0),
  started_at  TIMESTAMPTZ NOT NULL,
  ended_at    TIMESTAMPTZ,
  status      VARCHAR(12) NOT NULL DEFAULT 'running'
              CHECK (status IN ('running','paused','completed','cancelled')),
  switch_count INT NOT NULL DEFAULT 0,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_focus_user_started ON focus_sessions(user_id, started_at DESC);
-- Only one running session per user
CREATE UNIQUE INDEX uq_one_running_focus ON focus_sessions(user_id) WHERE status IN ('running','paused');

ALTER TABLE activity_sessions
  ADD CONSTRAINT fk_act_focus FOREIGN KEY (focus_session_id)
  REFERENCES focus_sessions(id) ON DELETE SET NULL;
```

### goals
```sql
CREATE TABLE goals (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id      UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  type         VARCHAR(30) NOT NULL CHECK (type IN ('daily_focus_min','max_task_switches','max_app_min')),
  target_value INT NOT NULL CHECK (target_value > 0),
  app_name     VARCHAR(255),                -- only for max_app_min
  is_active    BOOLEAN NOT NULL DEFAULT TRUE,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_goals_user ON goals(user_id) WHERE is_active;
```

### notification_events (table ready, tracking later)
```sql
CREATE TABLE notification_events (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  client_id   UUID NOT NULL,
  user_id     UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  app_name    VARCHAR(255) NOT NULL,
  received_at TIMESTAMPTZ NOT NULL,
  UNIQUE (user_id, client_id)
);
CREATE INDEX idx_notif_user_time ON notification_events(user_id, received_at DESC);
```

### refresh_tokens
```sql
CREATE TABLE refresh_tokens (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  token_hash TEXT NOT NULL UNIQUE,          -- store hash, never raw token
  expires_at TIMESTAMPTZ NOT NULL,
  revoked_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_rt_user ON refresh_tokens(user_id);
```

## 4. Useful Queries

**Today's screen time (excluding idle):**
```sql
SELECT COALESCE(SUM(duration_sec),0) AS active_sec
FROM activity_sessions
WHERE user_id = :uid AND is_idle = FALSE
  AND started_at >= date_trunc('day', now() AT TIME ZONE :tz) AT TIME ZONE :tz;
```
**Top apps:**
```sql
SELECT app_name, SUM(duration_sec) AS total_sec, COUNT(*) AS sessions
FROM activity_sessions
WHERE user_id = :uid AND is_idle = FALSE AND started_at >= :from AND started_at < :to
GROUP BY app_name ORDER BY total_sec DESC LIMIT 10;
```
**Task switches (non-idle session count - 1):**
```sql
SELECT GREATEST(COUNT(*) - 1, 0) FROM activity_sessions
WHERE user_id = :uid AND is_idle = FALSE AND started_at >= :from AND started_at < :to;
```
**Hourly timeline:**
```sql
SELECT date_trunc('hour', started_at AT TIME ZONE :tz) AS hr,
       SUM(duration_sec) FILTER (WHERE NOT is_idle) AS active_sec,
       SUM(duration_sec) FILTER (WHERE is_idle)     AS idle_sec
FROM activity_sessions WHERE user_id = :uid AND started_at >= :from AND started_at < :to
GROUP BY 1 ORDER BY 1;
```

## 5. Local SQLite Buffer (Desktop)
```sql
CREATE TABLE pending_sessions (
  client_id TEXT PRIMARY KEY,
  app_name TEXT NOT NULL,
  window_title TEXT,
  is_idle INTEGER NOT NULL,
  started_at TEXT NOT NULL,
  ended_at TEXT NOT NULL,
  focus_session_id TEXT,
  synced INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX idx_pending_synced ON pending_sessions(synced);
```

## 6. Data Retention & Privacy
- Raw `activity_sessions` kept 12 months (cron job deletes older).
- `DELETE /users/me/data` wipes sessions, focus sessions, goals, notifications.
- `window_title` stays NULL unless `store_window_titles = TRUE`.

## 7. Migrations
Alembic only. Never edit DB by hand in prod. One migration per change, named `YYYYMMDD_short_desc`.
